# Samir Zahri — Artistic Portfolio

Static GitHub Pages portfolio focused on cinema, photography and current research.

## Editorial structure

1. LIVRAISON — screenplay + research in development. No fabricated production stills.
2. WHAT IS REAL? — real camera reference → digital twin → language/caption → public belief.
3. Documented cases — only the begging-scene reception capture and the invented doctor-biography capture.
4. Selected camera-based cinema — four primary films + additional archive.
5. Photography — curated into Work & Territory, Thresholds & Night, Gesture & Cultural Material.
6. Synthetic image — only digital-twin research, clearly separated from camera photography.
7. AI moving image — LE TUBE shown through the playable film only; no LE TUBE screenshots.
8. Practice / trajectory.

## Languages

English, French, Spanish, German and Arabic. Arabic switches the page to RTL.

## GitHub Pages

Upload the complete contents of this folder to the root of a GitHub repository. In Settings → Pages choose Deploy from a branch, select `main`, then `/ (root)`.

All asset paths are relative and the project requires no backend or build step.
